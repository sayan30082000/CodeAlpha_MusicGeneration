AI Music Generator

An LSTM neural network trained on 365 Bach chorales writes a brand-new melody every time you press Generate. It runs entirely in your browser.

Piano roll

Press Generate to compose a melody.

How it works

  1. Data: 365 Bach chorales (MIDI) were turned into note tokens like E5_1.0 (note E5 for one beat) with music21.
  2. Model: a 2-layer LSTM (256 units, ~980k weights) learned to predict the next note from the previous 32 — trained in PyTorch.
  3. Generation: it starts from a short phrase of a real chorale, then picks each next note from its predicted probabilities (top-8 sampling with a temperature).
  4. Sound: notes are played with the Web Audio API and can be saved as MIDI or WAV.
